# Kiro Web

**Kiro Web** — проект модернизации Android-веб-сервера от **KirDev Studio**.

**Автор и разработчик форка:** [KirDev / kirdev07](https://github.com/kirdev07)  
**Статус:** подготовка исходников и аудит совместимости; готовая сборка пока не опубликована.

## Цель

Создать самостоятельное Android-приложение, которое позволяет запускать локальный веб-сервер прямо на смартфоне **без root, Termux и сторонних приложений**. Планируется поддержка современных версий Android и удобная панель управления.

## Планируемые возможности

- HTTP-сервер для сайтов и локальных веб-приложений
- PHP runtime
- SQLite и, при технической возможности, MariaDB
- FTP/SFTP с безопасной настройкой доступа
- HTTPS и управление сертификатами
- Файловый менеджер и журналы сервера
- Современный интерфейс Material 3, светлая и тёмная темы
- Работа через foreground service с учётом ограничений Android

> **Важно:** перечисленные функции — цели разработки, а не подтверждённые возможности текущей версии. Поддержка Android 13–17, ARM64 и упаковка нативных компонентов в один APK требуют отдельной реализации и тестирования.

## Разработка

1. Перенос и сохранение исходного кода DroidPHP, включая лицензионные уведомления.
2. Аудит старого Android-проекта и нативных серверных компонентов.
3. Восстановление сборки и обновление Android toolchain.
4. Рефакторинг, Kotlin и Material 3.
5. PHP, базы данных, FTP/SFTP, HTTPS и веб-панель.
6. Тестирование на современных устройствах и выпуск APK.
